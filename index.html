사무실 맵 사용하기

  1. 찾기

    비품명·캐비닛 번호·좌석 이름을 검색하세요. 띄어쓰기와 영문 대소문자는 구분하지 않습니다.

  2. 확인하기

    캐비닛에 마우스를 올리면 요약, 클릭하면 단별 비품이 열립니다. 키보드 Tab과 Enter로도 선택할 수 있습니다.

  3. 정리하기

    상세 패널의 ‘비품 추가’나 각 비품의 ‘수정’을 누르세요. 수정 화면에서 캐비닛 1~10과 칸을 선택하면 물품 위치를 옮길 수 있습니다. 지도 번호 자체는 원본 도면에 고정됩니다.

  4. 이름과 시점 바꾸기

    지도에서 좌석·자산 이름을 클릭하거나 ‘이름 편집’을 누르세요. 시점 좌우 버튼은 90°씩 회전하며 평면 보기의 방향은 원본 도면에 고정됩니다.

  5. 보관하기

    변경은 공용 구글 시트에 저장됩니다. 약 8~16초 간격으로 다른 사람의 수정사항을 확인합니다. 같은 항목을 먼저 수정한 사람이 있으면 이번 저장은 적용되지 않습니다. 작성 중인 화면은 자동으로 바꾸지 않습니다. 새 백업에는 이름도 포함됩니다. 구버전 백업을 가져올 때는 현재 이름이 유지됩니다. 가져오기는 현재 비품 목록 전체를 교체하며 교체 전 자료는 자동으로 한 번 보관합니다.

1번의 원본 표는 세 단이 병합되어 ‘전체칸’으로 등록했습니다. 9번 상단의 ‘빈칸’은 비품을 등록하지 않은 상태로 반영했습니다. 도면의 초록색 선은 사진 속 파티션으로, 점선은 벽 없이 표현했습니다. 공간은 안내용으로 단순화했습니다.
